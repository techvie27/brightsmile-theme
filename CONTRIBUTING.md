# Contributing

## Branch rule
- Never work directly on `main`.
- One ticket = one branch.
- Name branches `feature/short-name` for new work, `fix/short-name` for bug fixes and `docs/short-name` for documents.

## Pull request rule
- Every change goes through a Pull Request.
- The CI check must be green before you merge.
- Merging to `main` runs the deploy job.

## Commit messages
Say what you changed and why. Example: "Add Doctor CPT with speciality field".
